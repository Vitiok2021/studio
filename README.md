
# Studio

## Опис
"Studio" — це лендінг для студії, яка надає послуги в сфері дизайну та творчих рішень. Сайт включає в себе розділи про послуги студії, портфоліо, відгуки клієнтів та контактну інформацію. Сучасний та адаптивний дизайн дозволяє користувачам швидко знайти потрібну інформацію.

## Технології
- HTML5
- SCSS
- JavaScript
- Адаптивна верстка (Flex, Grid)
- Слайдери та анімації для взаємодії з користувачем

## Демо
[Studio](https://vitiok2021.github.io/studio/) — сайт студії дизайну

## Особливості
- Адаптивний дизайн, оптимізований для мобільних та десктопних пристроїв
- Інтерактивні елементи, такі як слайдери та анімації
- Розділ з відгуками клієнтів та портфоліо для демонстрації виконаних робіт
